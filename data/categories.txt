# 効果一覧のカテゴリ（効果を選ぶ画面の並び）
#
# ・「■ カテゴリ名」の行がカテゴリです。上から書いた順に画面に並びます。名前も自由に変えられます。
# ・その下に、そのカテゴリに入れる効果を1行に1つ書きます。
#   レベル違い（+1／+2 など）は書かず、効果の名前だけ書きます（例：物理攻撃力上昇）。
# ・効果の行を別のカテゴリの下に移すと、そのカテゴリに入ります。行の順番がカテゴリの中の並び順になります。
# ・ここに書いていない効果は、もとのカテゴリのまま一番下に並びます。
# ・# で始まる行と空行は無視します。
# ・デメリットもここで分けられます（「デメリット（…）」のカテゴリ）。
# ・直したら、アプリを開き直すと反映されます。
#   書き間違いがないかは  python tools\check_categories.py  で確かめられます。
